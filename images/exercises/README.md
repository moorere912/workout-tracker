# Exercise photos

Drop photos here to make them show up in the app's "how to" popup (tap any
exercise name). Completely optional per-exercise — any exercise without
photos here just shows a "Search a demo video" link instead, so nothing
looks broken while you add these gradually.

## Naming

For a given exercise, save up to 2 photos as:

```
<exercise-id>-1.jpg
<exercise-id>-2.jpg
```

`.jpeg` and `.png` also work. The app looks for `-1` first, then `-2`; either
one alone is fine (you don't need both).

## Getting them onto the live site

Saving files here on your computer isn't enough by itself — like any other
change, they need to be pushed to GitHub for the live app to see them.
Ask in chat once you've added some and they'll get pushed along with
everything else.
